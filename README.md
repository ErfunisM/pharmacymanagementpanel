# Pharmacy Management Panel
A web-based dashboard for managing pharmacy operations, medicines, and inventory.

## Features
- Medicine inventory management (add, edit, delete)
- Stock tracking and low-stock alerts
- Sales and prescription records
- Search and filter medicines
- User-friendly dashboard interface
